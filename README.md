#  Harit Sampada – Online Crop Suggestion Platform

**Harit Sampada** is an online crop suggestion platform designed to help farmers make informed decisions about crop selection based on their geographical location, agricultural conditions, and seasonal requirements. The platform aims to support sustainable agriculture by providing relevant crop recommendations and useful agricultural information through a simple and user-friendly interface.

The primary objective of Harit Sampada is to reduce uncertainty in crop selection and help farmers identify suitable crops for different seasons. By using location-based information, such as district details and land identification codes, the platform can provide crop suggestions that are relevant to the selected agricultural region.

##  Project Objectives

* **Crop Recommendation:** Suggest suitable crops according to the farmer's location and selected season.
* **Location-Based Analysis:** Use district information and land identification codes to identify relevant agricultural data.
* **Seasonal Planning:** Help farmers explore appropriate crop options for different agricultural seasons.
* **Data-Driven Decisions:** Provide recommendations based on available agricultural reference data.
* **Farmer-Friendly Interface:** Offer a simple and accessible platform that makes crop-related information easier to understand.
* **Sustainable Agriculture:** Encourage informed crop selection and support better agricultural planning.

##  Key Features

* **Location-Based Crop Suggestions:** Generate crop recommendations using the available location and land-related inputs.
* **Season Selection:** Allow users to select an agricultural season to receive relevant crop suggestions.
* **District-Wise Information:** Organize agricultural reference data according to districts.
* **Crop Scoring System:** Evaluate available crop options using predefined scoring logic.
* **Agricultural Reference Database:** Store and process crop, district, and related reference information.
* **Simple User Interface:** Provide an easy-to-use interface for entering information and viewing recommendations.

##  Technology Stack

The project uses a combination of frontend and backend technologies to provide an interactive and functional web application.

* **Frontend:** HTML, CSS, and JavaScript
* **Backend:** Node.js and Express.js
* **Data Processing:** JavaScript-based crop scoring and recommendation logic
* **Database and Reference Data:** Structured agricultural datasets and JavaScript data files
* **Testing:** JavaScript-based test scripts for checking application functionality and recommendation logic

##  How It Works

1. The user opens the Harit Sampada web application.
2. The user provides the required location details, such as a district or land identification code.
3. The user selects the relevant agricultural season.
4. The platform processes the supplied information using its available agricultural reference data and predefined recommendation logic.
5. The system evaluates suitable crop options using its crop-scoring mechanism.
6. The platform displays relevant crop suggestions to help the user make a more informed decision.

##  Project Vision

Harit Sampada aims to make agricultural information more accessible and useful for farmers by combining location-based inputs, seasonal requirements, and structured crop data in a single digital platform.

The long-term vision is to develop the platform into a more comprehensive agricultural decision-support system that can incorporate additional factors, such as soil characteristics, water availability, weather conditions, and historical agricultural data, as these capabilities become available.

By making crop-related information easier to access and understand, Harit Sampada seeks to contribute to informed crop selection, improved agricultural planning, and sustainable farming practices.

##  Current Development Status

Harit Sampada is currently under development as a web-based crop suggestion platform. Its existing project structure includes frontend files, backend services, crop recommendation modules, district-wise reference data, and testing scripts.

The current implementation focuses on providing crop suggestions using available reference data and predefined rules. Advanced features, such as machine-learning-based predictions, can be considered for future development.
